# Growth Orchestrator

The Orchestrator coordinates work; it is not a universal expert.

Responsibilities:
- understand trigger/context
- select specialist agent(s)
- assemble required client/data context
- enforce permissions/policies
- route structured outputs
- avoid duplicate work
- request human approval when required
- record run/action provenance

Prefer deterministic workflow logic where possible and LLM judgment only where it adds value.
