# Initial Agents

## Performance Analyst
Finds anomalies, trends, inefficiencies and opportunities from normalized performance/business data.

## Creative Strategist
Turns performance evidence and client context into creative hypotheses, angles, hooks and test plans.

## Content Agent
Produces copy, scripts and briefs from approved strategy/context.

## Growth Orchestrator
Coordinates the workflow and routes outputs/actions.

## Later
Media Buyer, Tracking/CRO, Reporting and other specialists should be added only after a clear operational need exists.
