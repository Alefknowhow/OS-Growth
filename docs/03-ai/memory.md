# AI Memory

Memory must be structured and evidence-linked.

Layers:
1. Raw evidence — metrics, events, source documents/references.
2. Derived observations — time-bound AI interpretations.
3. Experiment learning — hypothesis, result, conclusion.
4. Stable client knowledge — approved facts/preferences/constraints.

Do not convert every model statement into durable memory. Store provenance, timestamps and confidence/validation status where useful.
