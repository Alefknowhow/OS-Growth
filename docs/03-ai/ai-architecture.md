# AI Architecture

## Initial team
Growth Orchestrator → Performance Analyst → Creative Strategist → Content Agent.

## Operating model
Agents consume structured context and call typed tools. Outputs should become structured artifacts: insights, hypotheses, briefs, tasks, experiments, reports or proposed actions.

## Closed loop
Data → Analysis → Decision → Action → Experiment → Result → Memory.

## Provider strategy
Use a provider abstraction so OpenAI and Anthropic models can be selected by capability/cost without coupling domain logic to one model vendor.
