# Core User Flows

## 1. New client (Auto CRM → Growth OS)
Deal won in Auto CRM → `crm.deal.won` → client created with prefilled profile (company, contacts reference, contracted scope, budget) → onboarding checklist → connections → media upload → readiness → first analysis.

## 2. Daily performance loop (automatic)
Intraday/daily sync → signal detectors → Performance Analyst insights → Media Buyer plans → Policy Engine → auto-execute (inside envelope) or Approval Inbox → execution → verification → outcome evaluation → digest.

## 3. Operator command
Voice/text → Command Interpreter → query answer | Plan | creative job | report → same governance as any plan.

## 4. Creative loop
Request or fatigue signal → brief → skill → assets + Higgsfield + motion graphics + copy → QA → internal/client review → publish Plan → performance → learnings.

## 5. Experiment loop
Hypothesis → design (variants, KPI, budget, duration) → Plan to launch → run → evaluation → conclusion → learning.

## 6. Reporting loop
Schedule → data snapshot → Reporting agent narrative → internal check (or auto-publish by policy) → portal → `growth.report.published` to Auto CRM.

## 7. Client-risk loop
Health deterioration (KPI off target, pacing, tracking break) → risk insight → `growth.client.risk_detected` to Auto CRM → relationship task for the account owner there.

## 8. Revenue feedback loop (M4)
Client conversion source (lead outcome, sale) → attribution identifiers → campaign/ad context → true CPA / ROAS → plans and learnings.
