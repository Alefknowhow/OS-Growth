# Core User Flows

## Daily performance loop
Sync metrics → detect meaningful change → analyze → recommend → create/route action → track outcome.

## Creative loop
Performance signal → creative hypothesis → concept/angle → copy/script/brief → task → asset → approval → publish/test → measure → learning.

## Experiment loop
Hypothesis → definition → execution → measurement → conclusion → memory.

## Revenue feedback loop
CRM sale/revenue event → attribution identifiers → campaign/ad context → CAC/ROAS/business outcome → optimization insight.

## Client-risk loop
Operational/performance signal → Growth OS risk insight → CRM relationship task/event when human client contact is needed.
