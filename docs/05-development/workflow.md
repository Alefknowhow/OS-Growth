# Development Workflow

1. Create/choose GitHub issue.
2. Create a focused branch.
3. Update .ai/CURRENT_TASK.md for substantial work.
4. Implement smallest coherent slice.
5. Run typecheck/lint/tests.
6. Update relevant docs/ADRs.
7. Open PR with scope, risks and verification.
8. Review (human + automated/Codex where configured).
9. Human merge.

Do not push feature work directly to main.
