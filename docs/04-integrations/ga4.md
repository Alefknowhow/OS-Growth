# GA4 Integration

GA4 will provide site/event/funnel context complementary to ad-platform data.

Goals:
- traffic and event trends
- landing-page/funnel signals
- conversion context
- campaign attribution support

GA4 does not replace CRM revenue truth when CRM sales/revenue data is available.

Phase: M5. GA4 data feeds signals (landing page conversion rate drop, tracking checks) and reports, through the same raw → normalized layering as ad data.
